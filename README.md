## ✨ Features

### 🎯 Aimbot
- **Mira automática** com suavização ajustável
- **Predição de movimento** do inimigo
- **Múltiplos alvos:** Head, Body, Nut
- **FOV ajustável** (raio de detecção)
- **Modo botão direito:** ativa apenas ao mirar

### 👁️ ESP (Visuais)
- **Caixas ao redor dos jogadores**
- **Linhas conectando ao jogador**
- **Wireframe** (visão através de paredes)
- **Chams** (destaque colorido de aliados/inimigos)
